   Validación en navegador (form-handler.js)
   - Nombre (mínimo 3 caracteres)
   - Email (regex válido)
   - Teléfono (7+ caracteres)
   - Proyecto (requerido)
   - Mensaje (mínimo 10 caracteres)
   - Términos (checkbox obligatorio)
        ↓
   Mapeo de proyecto: slug → ID
   (ciudad-del-este → 1, etc)
        ↓
   Envío JSON a endpoint PHP via fetch()
   {name, email, phone, message, property_id}
        ↓
   Recepción en leads.php
        ↓
   Validación de JSON
   - ¿Es JSON válido?
   - ¿Contiene campos requeridos?
   - ¿Email es válido?
        ↓
   Sanitización de inputs
   - htmlspecialchars() en name, email, phone
   - htmlspecialchars() en message
        ↓
   Prepared Statement (SQL seguro)
   INSERT INTO leads (name, email, phone, ...)
        ↓
   MySQL ejecuta, genera ID
        ↓
   Respuesta HTTP 201 JSON
   {"success": true, "data": {"id": 23}}
        ↓
   JavaScript muestra mensaje de éxito
   "¡Gracias por tu interés! Un asesor te contactará pronto"
        ↓
   Lead visible en BD:
   SELECT * FROM leads WHERE id = 23;
